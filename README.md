# MOS Scaling VLSI Blog

An original 500–800 word educational blog on **Types of Scaling in MOS Technology: Constant-Field and Constant-Voltage Scaling**.

## Assignment requirements covered
- Original 500–800 word blog
- Real-world applications and societal benefits
- Original topic infographic with figure caption
- Direct connection to VLSI module concepts
- SDG 9: Industry, Innovation and Infrastructure mapping
- Five authentic references (IEEE, journal, Elsevier and United Nations)
- Future scope, challenges and original observations
- Responsive GitHub Pages-ready design

## Files
- `index.html` — complete blog
- `style.css` — responsive styling
- `assets/mos-scaling-infographic.png` — original topic infographic
- `assets/mosfet-dimension-scaling.svg` — original MOSFET dimension-scaling diagram
- `assets/electric-field-comparison.svg` — original constant-field vs constant-voltage diagram
- `assets/scaling-real-world-applications.svg` — original real-world VLSI applications diagram

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for deployment.
